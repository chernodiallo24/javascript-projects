# Rock Paper Scissors Game

## Overview

This project is an interactive "Rock Paper Scissors" game built using "HTML, CSS, and JavaScript".  
The player competes against the computer, which randomly selects Rock, Paper, or Scissors.  
The game tracks scores, displays results, and allows the user to reset the game.

This project was created to strengthen my understanding of:

- JavaScript logic and conditionals
- DOM manipulation
- Event listeners
- Random number generation
- Game state management

---

## Features

- Player vs Computer gameplay
- Random computer choice generation
- Score tracking system
- Win / Lose / Draw messages
- Background color feedback
- Reset ("Play Again") functionality
- Clean and responsive layout

---

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla JS)

---

## How the Game Works

1. The player selects "Rock", "Paper", or "Scissors"
2. The computer randomly selects one option
3. The game compares both choices
4. The result is displayed:
   - Winner
   - Loser
   - Draw
5. Scores update automatically
6. The user can reset the game using the "Play Again" button
