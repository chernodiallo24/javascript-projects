This project is a simple interactive number-guessing game built as part of a JavaScript learning course.  
The HTML and CSS starter files were provided, and I implemented all the JavaScript logic, user interaction, and game flow.


Features

- Random number generation  
- User input handling  
- DOM manipulation  
- Event listeners  
- Score tracking  
- High score system  
- Win/Loss messages  
- Responsive UI updates  
- Cleaned and refactored code using DRY principles

- What I Learned

- How to update the UI using JavaScript  
- Writing and organizing functions  
- Using event listeners for user actions  
- Handling game logic and edge cases  
- Working with DOM elements  
- Beginner level debugging  
- Version control with Git and GitHub
